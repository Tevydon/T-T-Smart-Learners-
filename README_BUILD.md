# T & T Smart Learners Android package

Version 3.0.8a. The current HTML app is included unchanged.

Open this project in Android Studio, allow Gradle sync, then choose:
Build > Build APK(s)

The debug APK is normally created at:
app/build/outputs/apk/debug/app-debug.apk

For a distributable release, use:
Build > Generate Signed App Bundle / APK
